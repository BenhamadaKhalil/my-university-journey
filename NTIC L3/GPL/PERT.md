# 🎓 **CHAPTER 6 — PERT-CHARGE & PERT-COST (BEST VERSION)**

---

## 🎯 **Why PERT-CHARGE?**

**PERT-CHARGE** is an **extension of PERT-TIME** that allows project managers to **take resources into account**, not only task durations.

📌 **Key idea:**

> Time alone is not enough — **resources determine feasibility**.

---

## 🧩 **From PERT-TIME to PERT-CHARGE**

|Method|What it manages|
|---|---|
|**PERT-TIME** ⏱|Task durations only|
|**PERT-CHARGE** 👥|Durations **+ resource allocation**|

📌 In PERT-CHARGE, tasks depend on:

- Duration
    
- Load
    
- Resource intensity
    

---

## 👥 **What Is a Resource?**

A **resource** is any **means necessary** to carry out a task:

- 👤 People
    
- 🛠 Equipment
    
- 💻 Technical tools
    

📌 In PERT-CHARGE, **each resource is represented as a calendar**.

---

## 📐 **Core Concepts in PERT-CHARGE**

### 🔹 1️⃣ Load (Charge)

- Amount of work needed
    
- Expressed in:
    
    - Man-days
        
    - Man-hours
        
    - Man-months
        
- Represents work done by **one person at 100% availability**
    

📌 Load = _how much work_

---

### 🔹 2️⃣ Duration

- Elapsed time between task start and end
    
- Expressed in days or hours
    

📌 Duration = _how long it takes_

---

### 🔹 3️⃣ Intensity

- Percentage of a resource’s availability assigned to the task
    
- Value between **0 and 1**
    
    - 1 = 100% dedicated
        
    - 0.5 = 50% availability
        

📌 Intensity = _how much of the resource is used_

---

### 🔹 4️⃣ Non-Working Time

- Weekends
    
- Holidays
    
- Breaks
    
- Closed days
    

📌 Must always be considered in duration calculation.

---

## 📐 **Fundamental Rule (VERY IMPORTANT)**

⚠️ **Never confuse load and duration**

|Concept|Meaning|
|---|---|
|Load|Amount of work|
|Duration|Elapsed calendar time|

---

## 🧮 **Duration Formula (PERT-CHARGE)**

```
Duration = (Load / Intensity) + Non-working time
```

📌 This formula is **central for exams**.

---

## 🧪 **Examples (Must-Know)**

### Example 1️⃣ — Same Load, Different Durations

Load = **10 man-days**

- 👤 1 person, 100% → **10 days**
    
- 👥 10 people, 100% → **1 day**
    
- 👤 1 person, 50% → **20 days**
    

📌 **Same load, different durations**.

---

### Example 2️⃣ — With Intensity

- Load = **40 hours**
    
- One person assigned at **25%**
    

```
Duration = 40 / 0.25 = 160 hours (+ non-working time)
```

---

## 🔁 **Forms of Resource Assignment**

A task can be defined by:

1️⃣ Duration + intensity  
2️⃣ Duration + load  
3️⃣ Load + intensity

📌 Internally, tasks are **always converted** into:

- Duration
    
- Intensity
    

before applying the PERT-CHARGE process.

---

## 🕸 **PERT-CHARGE Network**

- Built on the **same logic network** as PERT-TIME
    
- Adds:
    
    - Resource calendars
        
    - Resource loads
        
    - Resource intensities
        

📌 Logical dependencies **do not change**, only calculations do.

---

## 💰 **PERT-COST (Extension)**

**PERT-COST** extends PERT-CHARGE to **cost management**.

It helps to:

- 💳 Optimize payment schedules
    
- 🔥 Control cost overruns on **critical tasks**
    
- 💡 Identify possible savings on **non-critical tasks**
    

📌 Focus: **cost control through planning**.

---

## 🧠 **How All PERT Versions Fit Together**

```
PERT-TIME → PERT-CHARGE → PERT-COST
```

|Version|Focus|
|---|---|
|PERT-TIME|Dates & deadlines|
|PERT-CHARGE|Resources & workload|
|PERT-COST|Financial control|

## 🧠 **Exam Tips**

- Load ≠ Duration ❌
    
- Intensity < 1 = partial availability
    
- Duration = Load / Intensity
    
- PERT-CHARGE extends PERT-TIME
    
- PERT-COST focuses on **cost control**
    
- Critical tasks matter most for **cost overruns**
