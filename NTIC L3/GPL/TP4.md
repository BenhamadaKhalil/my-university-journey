# ✅ ÉTAPES POUR FAIRE LE PROJET DANS MS PROJECT

---

## 🔹 ÉTAPE 1 : Créer le projet

1. Ouvrir MS Project
2. Fichier → Nouveau → Projet vierge
3. Fichier → Enregistrer sous
4. Nom : ProjetTP4

---

## 🔹 ÉTAPE 2 : Paramétrer le calendrier

### 2.1 Définir la semaine de travail

1. Projet → Modifier le temps de travail
2. Copier le calendrier Standard
3. Renommer : Calendrier TP4

---

### 2.2 Jours ouvrés / chômés

* Dimanche → jour ouvré
* Vendredi + Samedi → jours chômés

---

### 2.3 Heures de travail

Pour chaque jour ouvré :

* 08:00 – 12:00
* 13:00 – 17:00

---

### 2.4 Jours fériés (exceptions)

Ajouter :

* 22 Avril 2023 → Aid El-Fitr
* 01 Mai 2023 → Fête du travail
* 28 Juin 2023 → Aid Al-Adha
* 05 Juillet 2023 → Fête indépendance

---

### 2.5 Date de début

1. Projet → Informations sur le projet
2. Date de début : 05 Mars 2023
3. Calendrier : Calendrier TP4

---

## 🔹 ÉTAPE 3 : Saisir les tâches (structure)

### 3.1 Créer les phases (tâches récapitulatives)

| Phase                         |
| ----------------------------- |
| Phase d’analyse               |
| Phase de conception générale  |
| Phase de conception détaillée |
| Phase de codage               |
| Phase d’intégration           |
| Phase d’installation          |

---

### 3.2 Ajouter les tâches sous chaque phase

👉 Exemple :

Phase d’analyse

* Identification des besoins – 4j
* Modélisation des besoins – 5j
* Maquette IHM – 5j

💡 Sélectionner les tâches → Indenter pour créer la phase

---

## 🔹 ÉTAPE 4 : Mettre les durées

Dans la colonne Durée, entrer :

* 4j, 5j, 10j, etc. (exactement comme le tableau)

⚠️ Les phases (récapitulatives) n’ont PAS de durée

---

## 🔹 ÉTAPE 5 : Définir les dépendances (liens)

### 5.1 Méthode simple

Dans la colonne Prédécesseurs, entrer le numéro :

| Tâche                 | Prédécesseur  |
| --------------------- | ------------- |
| Modélisation besoins  | 1.1           |
| Maquette IHM          | 1.2           |
| Modélisation statique | 1.2           |
| Codage module 1       | 2.1, 2.2, 3.1 |
| etc…                  |               |

👉 Utiliser exactement le tableau fourni

---

## 🔹 ÉTAPE 6 : Créer les ressources

1. Affichage → Feuille de ressources
2. Entrer Nom / Groupe / Coût / Capacité
3. Sauvegarder

---

## 🔹 ÉTAPE 7 : Affecter les ressources

1. Revenir à Diagramme de Gantt
2. Cliquer sur une tâche
3. Ressource → Affecter des ressources
4. Choisir la bonne ressource

⚠️ Respecter :

* rôle correct
* pas de surcharge
* optimisation du coût

---

## 🔹 ÉTAPE 8 : Vérifier les surcharges

1. Affichage → Utilisation des ressources
2. Si rouge → corriger l’affectation

---

## 🔹 ÉTAPE 9 : Afficher le chemin critique

1. Affichage → Diagramme de Gantt
2. Format → Tâches critiques
3. Barres rouges = chemin critique

---

## 🔹 ÉTAPE 10 : Ajouter les colonnes demandées

Ajouter :

* Travail
* Coût
* Marge totale

👉 Clic droit sur en-tête → Insérer colonne

---

## 🔹 ÉTAPE 11 : Vérifications finales (TRÈS IMPORTANT)

✔ Pas de tâche sans ressource
✔ Pas de surcharge
✔ Coût total affiché
✔ Chemin critique visible
✔ Phases bien structurées

---

## 🎯 CE QUE LE PROF ATTEND

> Un projet bien structuré, logique, respectant les contraintes, avec calendrier personnalisé, ressources cohérentes, coût optimisé et chemin critique visible.
