# 🎓 **CHAPTER 3 — PROJECT PLANNING (COMPLETE & EXAM-READY)**

---

## 🎯 **Objectives of Project Planning**

Project planning aims to **master and control project resources** in order to:

- ⏱ Respect **deadlines**
    
- 💰 Control **costs and budget**
    
- 👥 Allocate **human & material resources**
    
- 📊 Monitor **progress vs planning**
    
- 🧠 Build a **project history** for future estimation
    

📌 Planning is the **basis for control and monitoring**, not just scheduling .

---

## 🔁 **Project Planning Cycle**

```
Plan → Execute → Monitor → Adjust → Deliver
```

Planning is **iterative**: adjustments may be required during execution.

---

## 🧱 **1️⃣ Project Breakdown (Core Concept)**

Projects are **complex** → they must be **decomposed** to be manageable.

### 🎯 Why Breakdown?

- Reduce complexity
    
- Avoid forgetting tasks
    
- Assign responsibilities
    
- Estimate cost & duration
    
- Enable effective monitoring
    

---

## 🧩 **2️⃣ Breakdown Structures (VERY IMPORTANT)**

| Structure | Question Answered | Purpose                 |
| --------- | ----------------- | ----------------------- |
| **PBS**   | What?             | Deliverables / products |
| **WBS**   | How?              | Tasks & activities      |
| **OBS**   | Who?              | Responsibilities        |
| **RBS**   | With what?        | Resources               |

⚠️ **Exam trap**:  
👉 _WBS ≠ PBS_  
👉 _WBS must be consistent with PBS_

---

## 📦 **3️⃣ PBS — Product Breakdown Structure (WHAT?)**

- Hierarchical decomposition of **deliverables**
    
- Focuses on **products**, not tasks
    
- Requires at least an **initial design**
    
- Used to:
    
    - Estimate costs
        
    - Estimate deadlines
        
    - Assign responsibilities
        

📌 PBS answers: **“What will be delivered?”**

---

## 🧩 **4️⃣ WBS — Work Breakdown Structure (HOW?)**

- Decomposition of **work and tasks**
    
- Lists all activities needed to produce the PBS
    
- Each task must:
    
    - Produce an identifiable result
        
    - Have a measurable workload
        
    - Respect logical constraints
        

📌 WBS answers: **“How do we do it?”**

---

## 👥 **5️⃣ OBS — Organization Breakdown Structure (WHO?)**

Defines **responsibilities and authority**:

- Who executes a task?
    
- Who validates it?
    
- Who declares it completed?
    

📌 OBS answers: **“Who does what?”**

---

## 🧰 **6️⃣ RBS — Resource Breakdown Structure (WITH WHAT?)**

- Identifies required resources:
    
    - Human
        
    - Hardware
        
    - Software
        
    - Financial
        

📌 RBS answers: **“With what resources?”**

---

## 📊 **7️⃣ Planning & Scheduling Techniques**

### 🧭 Main Objective

Determine **start & end dates** of tasks.

Two approaches:

- **Task planning**
    
- **Resource scheduling**
    

---

## 📅 **8️⃣ Gantt Chart — Time Representation**

- Calendar-based task visualization
    
- Shows:
    
    - Duration
        
    - Start / end dates
        
    - Parallel tasks
        

❌ Weak at showing dependencies  
📌 Answers: **WHEN?**

---

## 🕸 **9️⃣ PERT — Logical Representation**

- Focuses on **dependencies & task logic**
    
- Used to:
    
    - Build task network
        
    - Calculate minimum duration
        
    - Identify critical path
        

📌 Answers: **WHAT depends on WHAT?**

---

### ⏱ PERT Time Estimation

| Estimate | Meaning     |
| -------- | ----------- |
| O        | Optimistic  |
| M        | Most likely |
| P        | Pessimistic |

```
Expected Time = (O + 4M + P) / 6
```

---

## 🔥 **🔟 Critical Path Method (CPM)**

- Longest path in the PERT network
    
- Tasks with **zero slack**
    
- Any delay ⇒ **project delay**
    

📌 **Critical tasks must never slip**

---

## 🎯 **11️⃣ Milestones & S-Curve**

### 🏁 Milestones

- Key validation points
    
- No duration
    
- Used for monitoring progress
    

### 📈 S-Curve

- Shows **cost or effort vs time**
    
- Used to compare:
    
    - Planned vs actual progress
        

---

## 🧠 **12️⃣ How Everything Fits Together**

```
PBS → WBS → OBS / RBS → PERT → CPM → GANTT
```

| Step                | Tool  | Goal           |
| ------------------- | ----- | -------------- |
| Define deliverables | PBS   | WHAT           |
| Define tasks        | WBS   | HOW            |
| Assign people       | OBS   | WHO            |
| Assign resources    | RBS   | WITH WHAT      |
| Analyze logic       | PERT  | DEPENDENCIES   |
| Protect deadline    | CPM   | CRITICAL TASKS |
| Visualize time      | Gantt | SCHEDULE       |

---

## ✅ **Final Exam Checklist**

✔ PBS ≠ WBS  
✔ WBS before Gantt  
✔ PERT before CPM  
✔ Critical path = zero slack  
✔ Milestones ≠ tasks  
✔ Planning = control tool
