# 🌐 **Chapter 1 — Introduction to Web Applications Development**

## 🎯 **What is the Internet vs the Web?**

### 🌍 Internet

- A **network of networks**
    
- Allows **data exchange** between computers worldwide
    

### 🕸 Web

- A **service running on the Internet**
    
- Used to **access information**
    
- Based on:
    
    - **HTML** → structure
        
    - **HTTP** → communication protocol
        
    - **URL** → resource address
        
- Accessed using **web browsers**
    

📌 **Memory trick**:

> **Internet = infrastructure**  
> **Web = service on top of it**

---

## 🔁 **How the Web Works (Web Operations)**

1. User enters a **URL**
    
2. Browser asks **DNS** for the server IP
    
3. Browser sends an **HTTP request**
    
4. Web server processes the request
    
5. Server sends back the **HTML page**
    
6. Browser displays the page
    

📌 **Shortcut to remember**:  
**URL → DNS → HTTP → Server → Response → Browser**

---

## 🧩 **What is a Web Application?**

A **web application** is:

- An **interactive software**
    
- Runs on a **remote server**
    
- Accessed via a **web browser**
    
- Allows users to **perform actions**, not just read content
    

🧠 Examples:

- Gmail
    
- Netflix
    
- Amazon
    
- Google Docs
    
- Canva
    
- WhatsApp
    

---

## 🌐 **Web Application vs Website**

| Aspect        | Website       | Web Application |
| ------------- | ------------- | --------------- |
| Content       | Mostly static | Dynamic         |
| Interaction   | Read-only     | User actions    |
| Functionality | Display info  | Perform tasks   |
| Example       | Blog          | Gmail           |

📌 **Key idea**:

> If users **interact**, it’s a **Web App**.

---

## 🏗 **Web Application Architecture**

A web application has **3 main components**:

```
Client (Browser)
   ↓
Front-End
   ↓
Back-End
   ↓
Database
```

### 1️⃣ Front-End

- What the **user sees & interacts with**
    
- Technologies:
    
    - **HTML** → structure
        
    - **CSS** → style
        
    - **JavaScript** → behavior
        

🧠 Think: **Face of the app**

---

### 2️⃣ Back-End

- Runs on the **server**
    
- Handles:
    
    - Logic
        
    - Requests
        
    - Authentication
        
    - Communication with database
        
- Languages:
    
    - PHP
        
    - Java
        
    - Python
        

🧠 Think: **Brain of the app**

---

### 3️⃣ Database

- Stores application data
    
- Managed by **DBMS**
    
- Common DBMS:
    
    - MySQL
        
    - PostgreSQL
        
    - SQL Server
        
    - MongoDB
        
    - Oracle
        

🧠 Think: **Memory of the app**

---

---

## 🧠 **Final Mental Model (Very Important)**

> **Front-End** → what I see  
> **Back-End** → what decides  
> **Database** → what remembers

---

## ✅ **Exam-Friendly One-Line Summary**

> A web application is an interactive program accessed via a browser, built using a front-end for interaction, a back-end for logic, and a database for data storage, all communicating through the web using HTTP.
