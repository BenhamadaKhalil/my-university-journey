# **📝 Java Threads – Cheat Sheet (Lab 1)**

## **1) What is a Thread?**

A **thread** is an independent flow of execution.  
Java programs start with **one thread** → the **main thread**.

---

## **2) Thread Life Cycle**

|State|Meaning|
|---|---|
|**New**|Thread created but `start()` not called|
|**Runnable**|Ready to run (waiting for CPU)|
|**Running**|Currently executing instructions|
|**Blocked / Waiting**|Waiting for resource / condition|
|**Timed Waiting**|Waiting for a limited time (`sleep()`, `join(x)`)|
|**Terminated**|Finished execution|

---

## **3) Creating Threads**

### **Method 1 → Extending Thread**

```java
class MyThread extends Thread {
    public void run() {
        // Code executed by the thread
    }
}
MyThread t = new MyThread();
t.start(); // start a new thread
```

### **Method 2 → Implementing Runnable**

```java
class MyRunnable implements Runnable {
    public void run() {}
}
Thread t = new Thread(new MyRunnable());
t.start();
```

**Difference:**

- `extends Thread` → class _is_ a thread
    
- `implements Runnable` → class is a _task_, still needs `Thread` to run  
    → **Runnable is recommended** (because Java supports only one parent class).
    

---

## **4) Useful Thread Methods**

|Method|Meaning|
|---|---|
|`start()`|Launches a new thread → calls `run()`|
|`run()`|The thread's code (do **not** call directly)|
|`sleep(ms)`|Pause the current thread|
|`join()`|Makes current thread wait for another to finish|
|`getId()`|Returns a thread's ID|
|`currentThread()`|Returns the thread currently running|

## **5) Exercise Summaries**

### **Ex1:** Two threads run in parallel:

- Thread 1 prints numbers 1→5 with **500ms** delay.
    
- Thread 2 prints letters A→E with **700ms** delay.
    

### **Ex2:**

Child thread computes **sum between a and b (excluding limits)**.  
Main waits using **`join()`** and prints result.

### **Ex3:**

Parent prints **its ID**, child prints **its ID + parent ID**.

### **Ex4:**

Compute `(a+b) / (c*d)` using **two child threads**:

- Thread 1 (**extends Thread**) → computes `a+b`.
    
- Thread 2 (**implements Runnable**) → computes `c*d`.
    
- Main prints final result.
    

### **Ex5 (Data Race):**

Two threads modify a **shared variable** → no synchronization → **incorrect output**.

**Data Race Conditions:**

1. Shared variable.
    
2. At least one thread writes.
    
3. No synchronization.
    

---

## **6) Avoiding Data Race**

Use one of the following:

```java
synchronized(method) { ... }
```

or

```java
AtomicInteger
```

or

```java
Locks (ReentrantLock)
```

---

## ✅ Pro Tips for Exams

- **Never call `run()` directly** → this does **not** create a new thread.
    
- Always use **`start()`** to create a parallel thread.
    
- Use `join()` when the **main thread must wait** for the result.
    
- If threads modify shared data → **synchronize**.
