# **Chapter 5: Software Licenses**

## **1. Concept of “Software License”:**
- A **software license** is a **contract** that defines the conditions under which the copyright holder allows a user (or another party) to use, broadcast, or modify a computer program.
- Licenses are **contracts** that help protect **authors**, **users**, and potential **development collaborators**.
- They typically **grant rights** (e.g., use of software) and often impose **obligations** that must be respected.

## **2. License Agreement:**
### **What Does a Software License Agreement Contain?**
- A **license agreement** details the rights that the copyright holder grants to the licensee, such as:
  - **Installation** and use of the software.
  - Making a **backup copy** of the software.
- Using software without a license is a **violation of copyright**.
  
### **Additional Conditions of License:**
- In addition to granting rights, the copyright holder may add requirements like:
  - **Prohibition** on using the software with others.
  - **Prohibition** on studying the software or publishing its performance measurements.
  
- By purchasing software, users essentially **obtain a license** and agree to the **End User License Agreement (EULA)**.
- **License grants rights to use** the software, but the user **does not own intellectual rights** over the software. They only have certain **privileges** tied to obligations toward the distributor or publisher.

## **3. End User License Agreement (EULA):**
- The **EULA** is a contract that binds the person installing the software to the software publisher.
- It includes terms that may involve:
  - Asking for **payment** in exchange for software use.
  - **Prohibiting copying** of the software.
  
- **EULA** (End User License Agreement) is the **French equivalent** of **CLUF** (Contrat de Licence Utilisateur Final).
  
### **Clauses in the EULA:**
- Common clauses in a **EULA** may include:
  - Allowing the publisher to **collect data** about the user.
  - Limiting the use of the software based on location or jurisdiction (e.g., restrictions based on **cryptographic software laws**).
  - Prohibitions on creating content with the software that may **harm** the publisher’s reputation.
  - Automatic **copyright** on works created using the software.

## **4. Approval of a License Agreement:**
### **How to Approve a Software License Agreement?**
- **Two main types of approval** for software license agreements:
  1. **Shrink-wrap Licenses**:
     - A label or insert on the software package may state that by removing the packaging, the user agrees to the terms of the license (even if the user hasn’t read the terms). 
     - This method is **legally controversial** in some countries. In some jurisdictions, contracts must be **signed** to be valid.
   
  2. **Click-through Licenses**:
     - **Click-through licenses** require the user to **click “I agree”** after reading the terms during installation (common with downloaded or pre-installed software).
     - This method is widely accepted and used in many software distribution models.

## **5. Example of End-User License Agreement (EULA):**
### **What Does a License Agreement Contain?**
- **Typical clauses in a EULA**:
  - **Ownership**: The software and its documentation are the **property** of the copyright holder.
  - **Prohibited actions**: Translation, decompiling, modification, and adaptation are prohibited.
  - The user **cannot delete or change** the license number or pass it to third parties.
  - **Rental and loan** of the software are prohibited.
  - **Backup copy**: The user may make one **backup copy** of the software.
  - **Single machine use**: The software can only be installed on **one machine** (one hard disk, screen, and keyboard).

### **Transfer of License:**
- The user **may transfer** their rights **permanently**, provided they **do not keep any copies**, uninstall the existing version, and transfer it **in full** (license, updates, documentation, and media). The recipient must accept the terms of the EULA.

### **Legal Consequences:**
- **Copyright violations** are punishable by law as **infringement** (in France, this may result in **two years imprisonment** and a **100,000 euro fine**).

### **Liability and Warranty**:
- The software is provided **without any warranty**. The author cannot be held liable for any **damage** caused by the software, including **loss of data** or **financial loss** resulting from its use.
- **Limitations of liability**: The author's liability is usually capped at the **amount paid** for the license.

## **6. Software Categories:**
From a legal perspective, software can be categorized into **three main types**:

### 1. **Proprietary and Paid Software**:
  - This software is sold to users, typically through specialized shops or online. The user does not **own** the software but only has a **license** to use it.
  - **Example**: **Windows operating system**.
  - The **source code** is **closed**, meaning users cannot modify it. Only the company holding the license can modify the software and issue updates.
  - Users generally cannot modify the software for their needs.
  
  - **Shareware**: A common distribution model where users get to try the software before committing to purchase. After a trial period, the user must pay to continue using the software.

### 2. **Free of Charge Software (Freeware)**:
  - This software is available **free of charge** and can be downloaded or distributed.
  - **Source code** is not modifiable, and the software is updated only when its creator decides to update it.
  - **Example**: **Star Office 5.2**.
  - Freeware is often provided as a **marketing tool** to build a user base before transitioning to paid versions.

### 3. **Free Software (Libre)**:
  - This type of software is **free** in terms of freedom, not price, allowing users to **modify**, **distribute**, and **improve** it.
  - The **source code** is open and can be modified legally.
  
  - **GPL (General Public License)** is an example of a **copyleft** license. It ensures that any derivative works must also be released under the same license.
  - **Richard Stallman**, the founder of the **Free Software Foundation**, created **copyleft** to ensure that software remains free and open.

### **The Four Freedoms of Free Software**:
1. Freedom to run the program, for any purpose.
2. Freedom to study the operation of the program and adapt it to needs.
3. Freedom to redistribute copies.
4. Freedom to improve the program and publish improvements.

## **Examples of Free Software**:
- **GNU/Linux**, **Apache**, **Mozilla Firefox**, and other widely used software.

---

## **Key Takeaways:**
- **Software licenses** are **contracts** that define the terms under which users can **use**, **modify**, or **distribute** software.
- **End User License Agreements (EULA)** are a specific type of software license that binds users to the terms of use.
- **Shareware**, **freeware**, and **free software (libre)** are the main types of software licenses, with different conditions on use, modification, and redistribution.
- **Proprietary software** is typically **closed-source** and sold under **strict licenses**, while **free software** grants users greater **freedom** to modify and share the software.
- **Licensing** is critical in ensuring both **rights** and **obligations** are respected between software authors and users.
