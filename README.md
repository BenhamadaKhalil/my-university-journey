## 🕸️ Interactive Knowledge Graph & Vault Architecture

This vault is fully connected using the **Map of Content (MOC)** methodology. Each module and semester acts as a local hub, establishing a beautiful, interconnected neural network of my academic studies without any orphan files.

### 🏗️ Vault Hierarchy & Link Flow
Our graph represents a multi-tiered knowledge pyramid, mapping the logical progression of my studies:
*   **Tier 0 — The Root (`README.md`):** The grand entrance and cognitive dashboard of the entire vault, connecting the years.
*   **Tier 1 — Semester Hubs (`NTIC L2/NTIC L2.md`):** Central portals representing academic semesters, bridging all courses taken.
*   **Tier 2 — Module Indexes (e.g., `AJEL/AJEL.md`):** Dedicated subject hubs mapping out lectures, canvases, PDFs, practical labs, and zip assets for a single course.
*   **Tier 3 — Individual Notes:** The core knowledge nodes (e.g. `Chapter 01 Intellectual Property.md`) holding lecture contents.

### 🌟 Key Graph Benefits
- **Zero Orphan Notes:** Every single note is directly reachable from a parent module, semester, or the root homepage.
- **Interdisciplinary Discoveries:** Visualizes key conceptual links between subjects, such as connections between *Database Transaction theories* and *Operating System Process Synchronization*.
- **Fluid Navigation:** Integrated bottom breadcrumbs let me jump up or down the academic hierarchy instantly.
